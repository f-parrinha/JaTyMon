# Failure Examples
This folder contains a project with one or more ill-formed typestates for each well-formedness rule of our typestates, breaking the corresponding rule for observing  __JaTyMon__ dectecting and printing the corresponding errors.  

We provide a [run-failtests.sh](https://github.com/f-parrinha/JaTyMon/blob/main/Scripts/run-failtests.sh) script in [Scripts](https://github.com/f-parrinha/JaTyMon/tree/main/Scripts) for executing these projects.
